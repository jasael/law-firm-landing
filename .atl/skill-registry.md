# Skill Registry

This project uses Spec-Driven Development (SDD) to implement high-quality features.

## Project Standards

### Tech Stack
- **Framework**: Astro (v6)
- **Styling**: Tailwind CSS (v4) with CSS Animations & Shapes
- **Components**: Astro Components
- **Language**: TypeScript

### Conventions
- **Component Architecture**: Atomic design, keeping layout, pages, and UI components distinct.
- **Design Language**: Minimalist, executive, premium design. Using deep navy/charcoal as base colors with gold/bronze accents and HSL palettes.
- **Responsive Layout**: Mobile first, completely responsive.
- **Interactive Elements**: Unique ID attributes on all buttons, forms, and interactive links to facilitate automated browser testing.
- **SEO Best Practices**: Proper title tags, meta descriptions, unique H1 tag, semantic HTML (header, nav, main, section, footer).
